# Resume layout

Навчальний проєкт з верстки резюме за готовим макетом.

## Опис

У проєкті зроблена сторінка резюме з двома основними частинами:

- ліва панель з фото, контактами, освітою та навичками;
- права частина з ім'ям, короткою інформацією про себе та досвідом роботи.

Верстка адаптивна: на менших екранах блоки перебудовуються один під одним.

## Технології

- HTML5
- CSS3
- Flexbox
- Media queries
- Семантичні теги

## Як запустити

Потрібно відкрити файл `index.html` у браузері.

## GitHub

Для завантаження проєкту на GitHub можна використати команди:

```bash
git init
git add .
git commit -m "add resume layout"
git branch -M main
git remote add origin https://github.com/USERNAME/resume-project.git
git push -u origin main
```

`USERNAME` потрібно замінити на свій нік на GitHub.
