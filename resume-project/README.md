# Resume Project

Адаптивная верстка резюме по макету.

## Что использовано

- HTML5
- CSS3
- Semantic tags
- Responsive layout
- Comments in code

## Структура

```text
resume-project/
├── index.html
├── style.css
├── README.md
└── images/
    └── avatar.png
```

## Как открыть проект

Откройте файл `index.html` в браузере.

## Как загрузить на GitHub

```bash
git init
git add .
git commit -m "Add resume layout"
git branch -M main
git remote add origin https://github.com/USERNAME/resume-project.git
git push -u origin main
```

Замените `USERNAME` на свой ник GitHub.
